# Code that reads like code

Native highlighting for Rust, TypeScript, JavaScript, and Python.

## Rust

```rust
fn main() {
    let message = "Hello, Omarkd!";
    println!("{message}");
}
```

## TypeScript

```typescript
export const greet = (name: string): string => `Hello, ${name}!`;
```

## JavaScript

```javascript
const reader = { fast: true, modern: true };
console.log(reader);
```

## Python

```python
def greet(name: str) -> str:
    return f"Hello, {name}!"
```

## Unknown language

```omarkd-unknown-language
This stays readable as plain code.
```
